# 💻 Meu Primeiro Commit - Projeto Responsivo

Este repositório é um marco na minha trajetória técnica, registrando o meu **primeiro commit oficial** utilizando Git e GitHub. O projeto consiste em uma página web estática construída com foco total em boas práticas de estruturação e **responsividade**.

O objetivo principal foi dominar o fluxo de controle de versão (Git) enquanto aplicava conceitos avançados de design responsivo para garantir que a interface se adapte com elegância a diferentes tamanhos de tela (monitores, tablets e celulares).

---

## 🚀 Funcionalidades e Aprendizados

- **Design Responsivo:** Implementação de técnicas de estilização fluida para adaptação automática do layout em dispositivos móveis.
- **Estruturação Semântica:** Uso correto das tags estruturais para melhorar a acessibilidade e o SEO da página.
- **Controle de Versão:** Aprendizado prático dos comandos fundamentais do Git (`git init`, `git add`, `git commit` e `git push`).

---

## 🛠️ Tecnologias Aplicadas

- **HTML5:** Criação da estrutura base semântica e organizada do site.
- **CSS3:** Estilização completa, uso de Media Queries para responsividade e efeitos de transição visual.
- **Git & GitHub:** Utilizados para gerenciar o histórico de alterações e publicar o portfólio na nuvem.

---

## 📈 Evolução Técnica

Como futura Engenheira de Software, este projeto representa o alicerce do meu aprendizado. Ele provou a minha capacidade de:
1. Configurar e utilizar ferramentas de versionamento profissionais (Git).
2. Compreender como construir layouts modernos que funcionam perfeitamente na mão do usuário (Mobile-First).
